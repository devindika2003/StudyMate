StudyMate is a cross-platform mobile application developed using React Native and the Expo framework, specifically designed to assist students in efficiently managing their daily academic tasks, study schedules, and long-term goals. The application features a clean, intuitive, and responsive user interface optimized for mobile environments, incorporating eye-comfort and accessibility-friendly color palettes to reduce eye strain during extended study sessions. Built with JavaScript and custom StyleSheet components, the project implements modern software development practices and utilizes Git and GitHub for version control. To execute and evaluate the project locally, clone the repository to your local machine, navigate to the project directory, install the necessary dependencies using npm, and initiate the Expo development server.
